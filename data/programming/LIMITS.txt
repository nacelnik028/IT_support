VÝUKOVÝ PYTHON · omezená podmnožina Pythonu 3, nikoli plný CPython
Podporuje print/input, int/float/str/bool/None, operátory, řetězce, list/dict/tuple/set, indexy a výřezy start:stop, if/elif/else, for/while, break/continue, funkce s výchozími a pojmenovanými parametry, jednoduché comprehension, f-stringy bez formátovacích specifikací, try/except, import math/random a virtuální soubory.
Vestavěné funkce: len, sum, min, max, sorted, abs, round, range, enumerate, zip a převody typů. math: sqrt/floor/ceil/sin/cos/fabs/pi/e. random: randint/choice; testy používají seed.
Limity: zdroj 32768 znaků, 8192 tokenů, 16000 kroků, 200 ms, rozpočet alokací 2 MiB, kolekce 2048 položek, řetězec/soubor 32768 znaků, výstup 8192 znaků, 16 souborů a 32 volání funkcí. Čísla do ±10^12. Překročení limitu nelze obejít pomocí except.
Soubory existují pouze v paměti běhu a po restartu programu se resetují. Jsou povolené názvy bez adresářů. Síť, systémové procesy, import os/sys, dynamické eval/exec, interní atributy a přístup k datům zařízení nejsou dostupné.
Nepodporuje třídy, generátory, async, lambda, dekorátory, global/nonlocal, libovolné balíčky, vícenásobné přiřazení, rozšířené slicing, generátorové výrazy a úplnou sémantiku všech vestavěných typů. Používej mezery a blokové příkazy na samostatných řádcích. Klíče slovníků a položky množin jsou skalární hodnoty.
HTML/CSS/JS · vlastní omezený náhled, nikoli úplný prohlížeč
Podporované elementy: html/head/body/title/meta/link, h1–h6, p, strong/em/mark/code/pre/br/hr, div/span, sémantické kontejnery, a, img, ul/ol/li, table/caption/thead/tbody/tfoot/tr/th/td a form/label/input/textarea/select/option/button. Komentáře, základní entity a číselné reference se zpracují. Podporuje vybrané volitelné koncové značky, nikoli úplný HTML5 parser a všechny opravy chyb prohlížeče. Maximálně 512 uzlů a 128 CSS pravidel. Inline layout a tabulky jsou výukové aproximace.
CSS: jednoduché selektory element, .class, #id, kombinace a potomci, seznam selektorů čárkou; kaskáda specificity/pořadí a inline style. color/background-color/background (jedna barva), font-size v px, nezáporné margin/padding v px, border (šířka solid barva), border-radius, gap, width; display:block/none/flex/grid, flex-direction:row/column, 1–4 grid sloupce (např. 1fr 1fr, repeat(2, 1fr)). Flex/grid a rozměry jsou zjednodušené. Procenta, media queries, pseudo selektory, animace, úplný flex sizing a jiné vlastnosti se nepoužijí. Neplatné/nepodporované deklarace se ignorují a nesplní CSS testy.
Formuláře: text, checkbox/radio/select, místní kontrola required/email/number. Neprobíhá síťové odeslání. #id posune náhled; externí odkaz pouze ukáže cíl. img src='server.svg' používá přibalený symbol; ostatní zdroje ukazují alternativní text bez přístupu k síti/zařízení.
JavaScript: document.getElementById('id'), document.querySelector('jednoduchý selektor'), aliasy const/let/var pro DOM prvek, addEventListener('click', function(){...}) nebo () => {...}, případně onclick = function(){...}. Obsluha může přiřadit textový literál nebo součet textových literálů do textContent vyhledaného prvku. Kliknutí skutečně mění strom i text v náhledu. Jiná syntaxe hlásí nepodporovaný JavaScript. Bez fetch, eval, časovačů, obecných výrazů nebo browser API. Limit skriptu 16 KiB.
Python funkce používají lokální parametry a globální jména; closures nejsou podporované. Windows i PICO používají stejné GDScript komponenty bez externího Pythonu/prohlížeče. Syntetické XR testy neprokazují tracking, komfort ani FPS na headsetu.
